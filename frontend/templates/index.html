New user guide

Start with the right screen, then let the system do the tracking.

Use this quick guide when you are new to Time Hub Network or need to know which feature to use for an attendance task.

01

Sign in using your assigned account

Your account permissions control what you can view, edit, approve, and export. Contact your administrator if your department, line, or shift access is incorrect.

02

Review the Dashboard

Check the live attendance summary for Present, Late, Absent, On Leave, and No Work employees. Use the shift filter before reviewing a specific line.

03

Use Attendance Logs for daily checks

Select the date and shift, then search by employee name or ID. Click an employee name to view attendance history. Use the Edit button only when a Time In or Time Out correction is needed.

04

Submit a correction request with complete details

Enter the correct time, select the appropriate status, and add a clear reason in Remarks. The request stays pending until it completes first approval and final HR approval.

05

Review and approve requests when assigned

Supervisors review requests within their allowed scope. Administration/HR completes final approval. Approved corrections update the attendance record; declined requests leave the original record unchanged.

06

Export and monitor exceptions

Use Missing Punches to find incomplete Time In/Time Out records, select a custom date range, then export to Excel. Attendance Logs also supports filtered daily and date-range exports.

What each role can do

Access is also limited by the department, section, line, and shift assigned to the account.

Line LeaderView dashboards, attendance logs, reports, and permitted request status. No edits or approvals.
StaffSubmit corrections and perform first approval for attendance requests in the assigned scope.
SupervisorView all attendance per department and checks the approval of the staffs.
Admin/HRReview final requests, apply approved corrections, and access company-wide functions based on account permissions.
Good practice: Check the selected date and shift before submitting or approving a correction. This keeps the audit trail accurate and prevents changes to the wrong attendance record.
